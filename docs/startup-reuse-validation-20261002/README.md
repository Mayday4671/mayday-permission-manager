## 启动与本轮修正

- 使用当前源码重新构建后台镜像，启动 `mayday` 项目的 MySQL、Java 后台和前端，保留原数据卷。
- 发现默认 Docker 内核缓冲只有 212,992 字节，UDP 收发测试要求 4 MiB，导致普通后台构建失败。修正测试条件：配置边界及实际缓冲启动保护始终执行；不满足条件时三项数据报集成测试明确跳过。正式 UDP 服务仍在缓冲不足时拒绝启动。
- API 权限测试同样明确区分正常启停与缓冲不足保护。只接受精确的缓冲不足错误；其他启动失败继续使测试失败。设置 `API_TEST_REQUIRE_UDP_BUFFERS=true` 后，缓冲不足也必须使验收失败。
- 修正复用文档中“没有 Git 元数据”的旧说明，以及误把已执行 V17 当作新迁移版本的描述；新增迁移应从下一未占用版本开始（当前为 V18）。
