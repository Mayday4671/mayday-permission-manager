## 本次交付

- 删除门户“资讯与帮助”整个标题横幅。搜索收进导航栏，保持可搜索、可清空及键盘提交。
- 公告、指南、动态、团队故事使用 `/categories/:categoryId` 独立栏目页；旧 `/?category=...` 书签自动迁移。栏目内搜索、分页和详情返回都保持栏目地址，清空搜索不会混入其他栏目。
- 共享文章卡片采用 16:9 封面、分类、标题、摘要、日期和真实浏览数。封面优先读取 Java 接口返回的已公开资源；没有封面或封面加载失败时使用本地默认配图。默认资产经 WebP 编码，四张合计约 554 KiB，原稿位于本机 `.local/portal-card-refresh/source-images/`。
- 桌面侧边距为 24–40px，手机 16px；大屏四列、桌面三列、平板双列、手机单列。页脚品牌、版权/备案、联系方式合并为一行，小屏自然换行；没有“首页”或后台登录入口。
- 工作台图表从固定 144px 改为随视口高度增长，使用 `clamp(144px, calc(100dvh - 720px), 560px)`；窄屏独立保持 240px。不新增页面标题或介绍块。
- 栏目页沿用后台设置的门户主题，不读取后台个人主题。
