# 前台门户第二轮优化验收

日期：2026-09-21。已更新到本机日常环境：<http://127.0.0.1:15173/>。

本记录承接客户门户第一轮验收，覆盖用户新增要求：缩小两侧留白、去掉装饰性宣传排版、前台不展示后台入口，以及继续改善客户查找和阅读内容的体验。

## 已交付

- 首页由固定最大宽度改为流式布局。1920px 视口两侧各 48px；2560px 两侧各 64px。标题、导航、搜索、列表与页脚使用同一对齐线。
- 移除大幅宣传标题、紫色装饰、皇冠图标和重复的分类快捷卡片；采用灰白底色、蓝色操作按钮、紧凑的资讯列表。分类集中在页头，公告、指南与联系方式作为辅助内容。
- 从公共页头、页脚中移除后台和登录入口，不再依据登录状态展示管理入口。后台原有路由及服务端权限仍生效。
- 首页与详情页复用文章摘要、侧栏文章列表、公开页面加载/失败提示和联系信息组件。无封面时不保留空白图片位置。
- 文章详情增加根据真实正文二、三级标题生成的目录，保留来源搜索/分类条件，并提供继续浏览入口。目录在富文本白名单处理之后生成，正文自带 ID、脚本、事件属性均不可信。
- 搜索清空按钮补充中文名称；错误提示不直接输出服务器异常详情；不存在或已下线的文章提供返回路径。

## 实测

1. 本地 TypeScript 检查与 Vite 构建通过；Docker 内生产构建通过。
2. 使用真实 Java 接口与现有 MySQL 公开内容，首页加载 4 篇文章。正式地址首页 HTTP 200，公开列表返回 4 条；没有替换为前端模拟数据。
3. 320×812、390×844、768×1024、1440×900、1920×1080、2560×1440 检查通过：文档 scrollWidth 等于 clientWidth，无页面横向溢出。320px 下分类栏在自身区域内横向滚动；正文不被挤宽。外侧留白分别为 12、12、20、36、48、64px。
4. 搜索“权限”返回 1 篇；进入文章再返回，搜索词和结果保留；清空搜索恢复 4 篇。无匹配结果时“查看全部内容”可恢复首页。
5. 分类“使用指南”返回 1 篇；文章内页头分类正确选中，返回链接保留 category=28。
6. 无效文章地址显示“这篇内容已下线或不存在”。详情页的“联系支持”定位到首页联系信息并移交键盘焦点。
7. 在临时组件验收页输入含 h2/h3、重复页面 ID、脚本和事件属性的正文：生成两个唯一目录锚点；脚本、图片和事件属性节点数为 0；目录点击后焦点进入对应标题。故意传入的服务器内部错误未显示。临时文件已删除，未进入生产产物。
8. 正式首页与详情页 DOM 中 /admin、/login 链接数均为 0。正式首页控制台无警告或错误；开发验收页删除时产生的旧热更新提示不属于生产页面错误。
9. 更新前后后端镜像一致、健康检查正常。只重建前端容器，数据库卷及现有授权不变。

当前数据没有推荐标记、封面、标签及多页文章，本轮不声称这些分支已用实际业务数据重新完成浏览器验收；目录和错误过滤使用单独的临时组件输入验证。已有文章标题、正文和网站配置继续由后台管理，本轮没有批量改写已发布内容。
