# 表格与批量数据

所有列表继续使用 `DataTable`，业务列表通过 `ResourcePage` 复用筛选、分页、操作权限与弹窗。桌面业务列可以拖动标题排序，拖动列边缘调整宽度，也可用边缘控件的左右方向键调整。列显隐、顺序、宽度和密度按账号、页面、嵌套列表保存。恢复默认同时清空列顺序和列宽；序号、勾选、操作列不会参与业务列排序。权限撤销后，旧的浏览器偏好不能恢复已不允许展示的列。

窄屏普通列表会使用同一份已授权列展示卡片，保留序号、勾选、业务操作与分页。菜单层级等需要树展开语义的列表保留层级表。布局仍按容器宽度压缩列，只有连最小阅读宽度也无法放下时才允许必要的横向滚动。

没有显式选择条数时，列表按窗口、工具栏、分页区及实际表格行/卡片高度计算安全条数，使用 1、3、5、10 的档位。手动选择的 20/50 等条数继续保存；点击“自适应条数”可回到自动计算。默认值不会覆盖用户明确保存的偏好。

具有该资源查看和导出权限的账号可以导出或打印当前页实际显示的列。它们只读取已经显示的文字，不从原始实体推断邮箱、电话等隐藏字段，也不导出操作按钮。所有 CSV 输出都会处理引号、换行和电子表格公式前缀。

## 用户导入

用户页面提供模板下载、CSV 预览、逐行错误清单和确认导入。导入要求独立的 `users:import`、`users:create` 权限，并要求账号具有全部用户数据范围。单次最多 1000 行、2 MB，只接受 UTF-8 CSV。模板根据当前账号的字段写权限生成。

- `username`：必填；3–32 位字母、数字或下划线，必须尚未存在。
- `nickname`：必填；最长 64 个字符。
- `password`：必填；10–64 位，含字母和数字，并符合原密码服务的 UTF-8 长度限制。密码保留原始字符，不自动移除边缘空格。
- `enabled`：`true` 或 `false`，留空时为 `true`。
- `email` / `phone`：仅拥有对应字段写权限或原整组敏感信息权限时允许填写。
- `departmentId`：可选；有效部门 ID，只有超级管理员可创建带部门的账号。
- `roleIds`：可选；多个有效角色 ID 用分号分隔，需要分配角色权限且不得超出自身委托权限。留空不自动授予任何角色。
- `postIds`：可选；多个有效岗位 ID 用分号分隔。

导入仅创建新账号，不会根据用户名更新已有账号。预览不写入数据库，也不会返回初始密码。错误清单只包含行号、用户名、姓名与错误说明。确认时服务器重新校验，并复用 `UserService.save` 的账号、部门、角色、字段权限和密码加密规则。账号写入和导入成功记录处于同一个事务，任何一行失败都会回滚整批。

每次选文件都会生成新的提交标识。网络重试继续使用相同标识和同一文件，服务器返回原成功结果，避免重复创建；复用标识上传不同文件会被拒绝。原始 CSV 和明文密码不存入数据库、浏览器持久存储或审计日志。

由于 CSV 可能包含初始密码，幂等文件校验在内存计算 SHA-256 后，使用原密码编码器的带盐 BCrypt 保存慢校验值。数据库不保存可直接用于高速猜测 CSV 密码的裸文件摘要；重试通过慢哈希核对，该校验值不参与账号登录。

## 异步导出

导出使用固定业务适配器及明确筛选，不接受 SQL、任意字段路径、Java 类名或执行命令。用户导出仍要求 `users:export` 和 `users:view`，每次查询都复用 SQL 数据范围与敏感字段策略。

每个账号最多两个未完成导出，每实例工作线程为两个，共享等待队列最多十六个。每次只读取 100 条并流式写出 CSV，最大 100000 条；超出限制时应缩小筛选。页面可以查看排队、执行、完成、失败、取消状态及处理数量，支持取消与显式重试。只有任务本人能查询和下载，超级管理员没有查看他人导出结果的隐含授权。

每批处理重新从数据库加载创建人并核实角色、字段权限和数据范围指纹，后台线程不会长期持有创建时的请求身份。下载时也重新比对指纹，账号停用或权限、范围变化后不能下载旧结果。导出属于生成时的内容快照，记录本身在生成后改变不会重写已完成的 CSV。

元数据存在 `sys_bulk_job`，队列存在 `sys_durable_task`，成功正文保存于 `sys_bulk_result`；`mayday.bulk.spool-directory` 是本实例受控缓存，默认在 Java 临时目录下。缓存使用独立临时文件及原子发布；本机缓存缺失时可从共享结果恢复，因此下载不要求粘性会话。目录由应用账号独占，不作为静态资源暴露。结果有效期 24 小时，定时有界清理。进程中断后其他工作器等待租约到期重新生成该导出；旧令牌不能覆盖接管者的进度、结果或成功状态。

页面重试复用原任务，不创建第二份成功结果；更改筛选必须创建新导出。取消先撤销租约，工作器批间检查后停止，任何迟到完成被拒绝。自动恢复有次数上限，达到上限后保留失败说明并允许本人显式重试；恢复时再次检查当前权限。详情、执行、取消、重试和下载都校验本人归属，不能仅凭任务 ID 管理其他人的作业。可用 `mayday.bulk.workers-enabled=false` 部署只处理 API 的实例，默认开启；租约及集群语义见[多实例说明](cluster.md)。

`mayday.bulk.cleanup-interval-ms` 默认 60000 毫秒；隔离验收可配置更短间隔，确认过期文件和元数据由真实清理流程删除。清理失败保留元数据等待下一轮重试。

## 新业务复用

实现并注册 `BulkResourceAdapter`，声明固定的 `resource`、标题、模板字段、预览规则、原子提交与分页导出。适配器必须复用业务服务原有授权逻辑，不能直接全表查询或绑定数据库实体。前端仅在确实注册了后端适配器的页面设置 `ResourcePage.bulkResource`，不要给所有 CRUD 页面自动生成不存在的导入入口。

通用层负责 CSV 边界、作业归属、幂等键、执行限额、进度、文件生命周期。业务层负责该业务的授权、数据范围、字段策略和状态规则。新增资源时同时登记独立导入权限、契约及相应安全回归用例。
