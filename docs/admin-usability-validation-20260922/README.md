# 后台查询与编辑体验检查（2026-09-22）

本轮根据“检查后台问题并补充实用功能”的授权完成公共组件改进。结果基于源码和自动化交互；内置浏览器连接连续失败，未取得本轮后台页面截图，不能视为完整视觉或全模块验收。

## 新增功能与使用方法

1. **常用查询**：列表工具栏书签按钮 → 保存当前条件 → 输入名称。再次点击该按钮可应用或删除查询。每个列表最多 8 条，同名不覆盖；关键词、启停状态以及已接入的业务条件会一起恢复。用户部门、内容分类/状态、通知状态、参数分组、日志日期和审批列表均已接入。
2. **表格记忆**：列显隐、表格密度和每页条数在刷新、重新登录后保留。按账号、页面和嵌套列表隔离，列设置内可恢复默认列。权限撤回后不会通过旧偏好恢复已移除的字段。
3. **编辑保护**：普通操作弹窗、个人资料及流程设计共享离开检查。切换菜单、后退、关闭或刷新标签页、浏览器刷新、退出登录均检查未保存修改；正在提交时暂不允许离开。多个编辑器分别登记，不再相互覆盖；同一次离开只确认一次。

偏好只保存在当前浏览器，不在设备间同步；常用查询为用户主动保存的筛选条件，不包含列表结果、表单正文、密码或令牌。可以从常用查询列表删除。禁用浏览器存储时退化为当前页面内存，保存查询会明确提示。

## 已修复的问题

- 搜索框清空后旧关键词仍参与查询：清空立即恢复查询，输入提交时去掉首尾空格。
- 总数缩减导致当前页越界：一次回到最后合法页，避免反复请求空页。
- 后台刷新后勾选记录已删除或不可操作：清理失效勾选，加载中或请求失败时禁用批量提交。
- 表格偏好原来仅在内存中：迁移到按账号与页面区分的浏览器存储。
- 弹窗只在点击取消时提醒：统一覆盖路由、页签、刷新和退出，程序设置字段也能识别修改。
- 个人中心表单可在提交期间继续编辑或重复提交：增加同步提交锁、禁用状态和离开保护。
