## 本轮发现和修正

- 会话期限固定且没有无请求期限或并发上限：增加启动配置与严格参数校验、并发账号行锁、最早会话撤销；认证和在线列表使用同一失效规则，不因第一次访问重新激活旧会话。
- 在线列表将会话全量加载后再分页：授权范围、启用账号、期限、关键词与计数改在 SQL 中执行，稳定双键排序，每页最多 100 条。
- 生产配置缺少明确拒绝条件：新增显式生产门禁，拒绝示例凭据、root 运行账号、演示初始化、API 契约开放和不合规 HTTPS 来源；既有示例管理员密码也不能靠修改环境变量假装完成轮换。
- 上传设置支持 100 MB，而代理只允许 11 MB：代理与应用最大请求均为 101 MB，单文件实际配置仍由业务校验；代理 413 和服务器异常统一为可读提示。
- 错误定位困难：服务端每请求生成关联号，日志与响应一致，客户端不能指定该号；前端服务错误显示定位号。
- 更新备份仅包含数据库，LOCAL 文件正文不可恢复：停写后生成数据库与本地文件同一恢复点，逐文件长度/SHA-256；新增真实移除、恢复、下载与缩略图回归。
- 升级依据只比较数据库版本，验收后改代码仍可发布：新增源码、构建配置模板和验收脚本摘要，包含未提交的新文件；升级前及构建后均检查相同输入，历史无摘要记录不放行。
- 720 高度桌面窗口空搜索多出纵向滚动：真实页面截图发现后减少空态装饰留白，保留内容及恢复按钮；更新后的页面另行实测，不能仅以 CSS 推算标记通过。
- 320 宽手机的搜索说明挤压标题：栏目搜索标题与说明在手机改为上下排列，关键词允许自然换行；在独立浏览器测得标题高度与单行行高一致，无横向溢出。
- SQL 会话字段注释仍写死原期限：V22 只同步三个 COMMENT，保留字段值、类型、索引和所有历史迁移校验和；外部数据库交付仍只有 `database/mayday.sql`。

所有新代码沿用统一命名、格式、DTO 白名单和详细中文注释；现有 Java/TypeScript 源码同时执行仓库规范检查。生产操作步骤、边界和恢复点要求已整理到 [生产指南](../production.md)、[升级说明](../upgrade.md) 和 [复用指南](../reuse.md)。
