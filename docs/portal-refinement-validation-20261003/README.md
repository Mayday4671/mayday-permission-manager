# 门户首页视觉纠偏（2026-10-03）

用户指出现有首页明显偏离已确认原型。本轮重新对照实际页面，修正构图、入口层次、精选样式、摄影和窗口比例，更新日常前端并实测。前次视觉通过结论过于宽松，本记录替代其首页视觉部分。

## 改动

- 缺省横幅使用完整摄影，消除左右接缝；浅色/暗夜为同构图实图。运营封面仍优先，并保留安全分区排版。
- 首页入口恢复图标底色、副标题及明确动作；名称和说明读取后台。
- 精选使用浅色/暗夜容器，去掉重复分类角标，调整摄影裁切，新增可用的查看更多。
- 主视觉、封面和间距随窗口适配；手机按实际内容自然纵向阅读。
- 栏目主视觉区分模板用途；分类留在当前栏目，搜索条件和正文跳转保持正确。
- 主题组件预览同步实际新照片，未将组件检查冒充后台正常登录的保存验收。

日常文章、首页排序、权限、后端、数据库和 UDP 均未修改。实际文章与原型示例不同，主色继续使用运营配置，不声称所有业务内容与拼版逐像素一致。
