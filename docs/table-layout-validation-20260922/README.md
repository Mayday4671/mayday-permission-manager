# 2026-09-22 菜单折叠与列表滚动修正

## 修改范围

- 菜单管理初次进入全部折叠，查询和刷新不会再自动展开。点击目录的任意位置均可展开/收起；回车、空格和展开图标也可操作，图标点击不会重复触发。
- 目录行合并内容单元格，名称与菜单数量完整显示。菜单列表保留名称、路由、权限、排序、状态、操作，将原来占位较大的说明和更新时间移出该列表；说明仍可在编辑弹窗查看和维护。
- `DataTable` 根据实际容器宽度测量并分配列宽；声明宽度只作为阅读偏好，先压缩可伸缩列，仅在最小可读宽度仍放不下时启用横向滚动。侧栏折叠、窗口缩放和弹窗打开会自动重新测量。
- 岗位、文件及所有使用公共表格的列表/详情弹窗均使用同一套宽度策略。去掉 ResourcePage 和审批详情的固定横向滚动宽度；序号、选择框及操作按钮保留必要空间，长文本省略并可查看原文标题。
- 检查后台壳层、侧栏、页签、工作台、查询工具栏、弹窗和流程设计器的滚动设置：无业务样式强制 `overflow-x: scroll` / `overflow-y: scroll`。后台最小高度改用动态视口，补充弹性容器宽度限制，避免移动浏览器地址栏及子元素固有宽度引起额外溢出。
- 长数据列表、用户主动展开大量菜单、长表单以及真正放不下的窄屏表格仍保留按需滚动，不裁掉内容或操作。
