# 主题抽屉验收（2026-10-02）

后台个人主题和网站配置中的前台主题已使用右侧抽屉，日常前端已更新。本轮完成真实后台浏览器检查；不将此前连接失败的检查追认为通过。

## 交付行为

- 桌面抽屉宽 480 px，窄屏使用可用宽度；标题和保存/取消固定，内容只在空间不足时自然滚动。
- 后台通过原页面即时预览，取消或关闭恢复已保存偏好。前台使用独立“效果预览”页签，草稿不影响后台或在线门户。
- 共用表单生命周期，防止重复提交；保存失败保留草稿，保存期间锁定控件及关闭操作。前台草稿关闭前提示放弃或继续编辑。
- 导入弹窗位于抽屉上方，沿用严格字段校验；普通业务编辑仍使用弹窗。
- 本轮只改变前端容器及间距，没有后端、接口、权限、数据库迁移或初始化脚本变更。前台保存仍走原版本校验和 `settings:update` 权限。

- 最终响应式 CSS 调整后，格式检查、TypeScript 与生产构建再次通过；仅重建并替换 `mayday-frontend-1`，后端和 MySQL 未重启或重置。
