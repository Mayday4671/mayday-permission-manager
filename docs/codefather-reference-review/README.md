## 对照发现与改动

- 旧版默认封面为通用办公照片，与内容主题关联弱。替换为指南、公告、产品动态、专题四类文字主题封面；后台上传的文章封面仍优先。四张 WebP 约 120 KiB，原图保存在 `.local/portal-topic-covers/`。
- 旧卡片内分类、标题、摘要、分隔线、日期分成多层，卡片偏高。调整为约 2.1:1 封面、15px 两行标题、13px 两行摘要、分类/日期/浏览数共一行；标题可访问名称保留完整内容。
- 导航去掉“服务中心”附加文字，高度降至 60px。桌面内容边距仍为 24–40px；主页顶部没有标题横幅。
- 指南侧栏使用小封面与标题；公告保留文字列表。栏目页移除重复的“其他栏目”导航，用真实公开公告、指南辅助阅读。
- 保留独立栏目路径、当前栏目搜索、文章返回来源、单行页脚和后台独立配置的前台主题。未复制对方会员价格、付费购买、社区登录、推广入口；未加入后台入口。
- 初轮超宽屏使用五列，实际仅有四篇文章导致空一列；复核后改回四列，见 `08-mayday-wide-first-pass.png` 与 `08-mayday-wide.png`。

## 边界

此次是按用户提供的教程目录视觉方向调整现有客户内容门户，不是复制 Codefather 的全部社区或课程产品。公开文章仅 4 篇，因此页面不可能具有参考站数十篇课程的内容密度；没有生成假文章、虚构热度或修改用户已有正文来填充版面。缺省图片是类别封面，需要文章专属封面时可从现有内容管理配置。

本次只改前台呈现，未更改 Java 鉴权、数据库脚本、发布审核规则或后台工作台图表。
