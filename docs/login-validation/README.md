状态：已完成并更新本机。登录按钮改为居中纯文字，去除右侧箭头和无关装饰；小屏幕登录卡片不再继承整屏高度。

## 使用与行为

输入账号密码后点击登录，弹出滑动拼图；对齐后由后端校验，通过后继续登录。可以换图或取消；支持触屏拖动，键盘方向键移动后按回车验证。验证失败更换新题，密码错误后需要重新验证。

服务端随机生成 PNG，答案不下发。挑战有效期 120 秒、一次尝试，通过凭证有效期 60 秒、一次消费，两者绑定账号及来源；保留原密码失败限流。状态有 TTL、来源请求配额及全局容量限制。不提供测试绕过开关，不包含第三方图片请求或外部验证码服务。

当前自托管拼图只作为基础反自动化门槛，可被图像算法识别，不能宣称阻止所有机器人；高风险系统应增加专业风控/MFA。当前为单实例状态，多节点需要共享存储和原子消费。具体协议见 [API](../api.md) 和 [权限说明](../permissions.md)。不涉及数据库结构变更，`database` 仍只交付一个 `mayday.sql`。
