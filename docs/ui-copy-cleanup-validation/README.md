# 后台重复标题与文案清理（2026-09-21）

根据用户再次明确的要求，后台正文直接进入数据或操作，页面名称由菜单、面包屑和标签页承担。

本次修改：

- 删除首页“数据概览”、日期及重复刷新整行，清理相关样式；刷新复用标签栏“刷新当前页”，已有查询失效和页面重载逻辑保持可用。
- 删除网站配置正文的重复页面标题和重复文本预览块，保留配置项、编辑入口及实际前台主题预览。
- 删除用户统计的权限解释横幅及长段说明，保留统计时段；活跃账号定义放到对应指标帮助，支持鼠标及键盘焦点。
- 删除监控组件的泛化标题行、品牌组件未使用的口号入口，以及主题预览里的装饰解释文案。“内容速览”改为明确的“最近内容”。
- 检查后台页面与通用组件的标题/介绍渲染位置。ResourcePage 原本只显示查询、操作和表格，继续保持；业务记录标题、分区名称、字段标签、弹窗操作标题与必要风险提示保留。
- 在 development-plan.md、development.md 以及 ResourcePage.title 的契约注释明确此约束，避免后续新增页面再次渲染重复标题。
