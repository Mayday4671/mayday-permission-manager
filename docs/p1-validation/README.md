# 公共框架与权限扩展验收记录

记录日期：2026-09-18。当前工作仍在继续，本文只记录已经取得的证据，不代表全部开发计划已交付。

## 已验证

- 页面登记统一提供路由、菜单分组与标签页；无权限页面不会被旧标签恢复。
- 用户邮箱、电话可分别设置读写权，兼容旧联系方式权限。
- 自定义部门按精确集合生效，与其他角色按记录集合合并；无资源查看权的角色不参与范围合并。
- 列设置、密度、查询分页共用组件；字典项等嵌套列表隔离状态与缓存键。
- 表单具备提交锁、错误定位、独立字段 ID、未保存修改提醒、内部滚动。
- 人员最小字段查询遵守用户范围；部门、角色、岗位、分类和标签选择器共用获取与错误处理。
- 批量启停在服务端逐项授权、校验版本，并在同一事务内提交或回滚。
- 字典类型与独立字典项分开维护，唯一值、排序、颜色、启停和跨类型隔离已测试；用户状态标签读取字典配置。
