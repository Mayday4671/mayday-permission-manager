# 前后台主题验收 · 2026-09-21

已完成并更新本机 `http://127.0.0.1:15173`。主题通过 [Ant Design 官方定制机制](https://ant.design/docs/react/customize-theme-cn/)实现，组件与业务 HTML 共同使用设计 Token 派生的颜色、背景、边框和圆角。

## 使用入口

- 后台右上角调色盘按钮“后台主题”：保存当前浏览器偏好，不改变门户。
- 系统管理 → 网站配置 → 前台主题 → 配置前台主题：保存全站门户配置到数据库，首页与文章详情共同使用。
- 两个弹窗均支持浅色、深色、跟随系统，七种预设色、自定义 HEX 颜色、圆角、紧凑布局；保存前预览、取消丢弃、恢复默认值。
- 前台只读取公开主题配置，不提供后台入口。未授权用户不能修改网站主题。

## 本机更新与回退

更新前停止后端写入，备份数据库及前后端旧镜像；更新后核对账号、角色、授权、配置、内容及流程定义的数据摘要和 Flyway 版本不变。无需新增数据库迁移；首次保存门户主题才建立对应参数。部署与镜像记录见 [deployment.json](deployment.json)。数据库备份仅保存在本机 `.local/theme-validation/`，不复制到交付文档。

