# 门户重构与栏目控制验收（2026-10-03）

用户确认第一套浅色设计，第三套作为同一布局的暗夜效果，并要求后台独立控制菜单栏目及其中的数据。本批已实现并升级本机日常环境；前台浏览器、真实接口、安装升级检查通过。**后台登录后的栏目保存、首页编排及内容发布浏览器链路仍待本次滑块验证授权，不标记整批验收完成。**

## 实现范围

- 首页：受管主视觉、公告条、栏目入口、有序精选、紧凑页脚；不暴露后台入口。
- 四种栏目模板：操作指南、日期公告、产品更新时间轴、团队图文杂志。正文保留目录、相关阅读、附件和联系支持。
- 栏目和分类分开管理；一个栏目关联多个有序分类，一个分类只归属一个栏目。选分类只筛选当前栏目。
- 内容编辑增加栏目与分类联动，复用封面、置顶、推荐、排期、审批及不可变线上修订；草稿修改不改变线上内容。
- 新增“门户栏目”管理页，含栏目配置、首页编排和前台主题；业务配置使用弹窗，完整主题使用用户指定的抽屉。
- 前台浅色主色、默认明暗、暗夜强调色及访客切换分别可控；后台个人主题不污染公共站点。
- 复用公共表格、弹窗/抽屉、查询状态、权限及编辑离开保护。UDP 模块未修改。

运营、权限及扩展步骤见 [门户指南](../portal.md)与[主题说明](../themes.md)。

最终真实 HTTP/MySQL 全套：升级库 **147 项通过**，新建库 **147 项通过**，均零失败、零跳过。门户专项覆盖：

- 未绑定分类拒绝发布，归属唯一，错误栏目/分类组合拒绝写入。
- 原版本过期 409、排序保留、历史引用删除保护。
- 栏目条件在 SQL 分页前执行，文章不混入其他栏目。
