状态：六项代码修改已构建并更新本机前端；后台浏览器验收等待本次滑块验证授权。不能把下方待验项目视为已经通过。

## 已完成的修改

1. 图表焦点：移除鼠标点击触发的默认黑色边框，保留主题色键盘焦点提示及 Recharts 无障碍交互。
2. 表格：所有业务列表及详情弹窗统一使用 `DataTable`，增加分页连续序号；表格外框、分隔线、表头和悬停色消费当前主题变量。
3. 菜单管理：按照实际侧栏目录展示“目录 → 页面”，支持全部展开/折叠、分级序号、查询后自动展开匹配目录。目录没有业务 ID，不出现编辑/删除操作；原有真实菜单编辑和后端路由校验保持。分组前逐页读取完整授权查询结果，避免同一目录被分页拆散。名称列始终保留。
4. 角色编辑：基本信息、操作权限、数据范围分为三个页签；权限使用模块列表与操作区，支持搜索、数量提示、模块全选/清空。切换页签和搜索不会清除隐藏权限，校验失败会切到错误所在页签。选中操作自动补齐查看/读取依赖，撤销查看会同时撤销依赖操作，批量勾选不能超出操作者自身授权。
5. 滚动条：页面、侧栏、弹窗及普通内部区域使用主题色；Ant 虚拟下拉列表滚动条也同步主题。标签页条原本隐藏滚动条的交互保持。
6. 文件中心：删除公共表格 `max-content` 撑宽方式，改用列宽合计作为可读最小宽度；文件名与上传人长文本省略并保留完整标题。文件列表含序号和操作的最小宽度为 720px，宽屏铺满可用空间，较窄手机保留必要横向滚动。
