# 客户门户使用路径验收（2026-10-03）

本轮结论：**公开客户门户的六步使用路径通过本机验收。** 在实际页面发现并修复五类问题，保留已经确认的首页视觉。没有把前端构建或截图检查扩大成整套后台、OA、V21 后台编排操作的验收。

## 环境与数据

- 日常门户 `127.0.0.1:15173`，真实 Java/MySQL 后端；本轮只更新前端镜像，后端、迁移和唯一 SQL 没有改动。
- 隔离门户 `127.0.0.1:15175` 接原隔离后端 `18081`，使用既有 V21 验收数据：35 篇公开内容、多分类、真实分页。没有向日常库导入演示文章。
- 一条合成客户反馈通过隔离页面提交，未填写邮箱；真实查询码仅留在验收会话，不进入本目录、网址或浏览器持久存储。截图中的全 `f` 查询码是不存在的合成输入。
- 使用恢复连接后的内置浏览器，直接点击、填写、翻页、返回、切换主题；本轮未处理任何登录验证码。
- 启动时日常服务未运行，页面提示连接失败。Docker Desktop 因关机遗留的两个运行时套接字目录启动失败。核对日志后把运行时目录保留为备份再启动，未重置 Docker、删除卷或清理数据库。服务恢复后页面自动重新读取内容，不能把这个过程写成“点击重试按钮成功”。

## 已修复的问题

- **P2：纯图片链接无名称。** 为共享卡片和故事旁栏图片提供明确阅读目标，普通标题保留可见名称。
- **P2：正文自动插入无关缺省摄影。** 仅在后台有实际封面配置时呈现文章封面；列表缺省摄影不改变正文。
- **P2：空搜索无直接恢复、标题及计数语义不准确。** 增加保留分类的清空操作，避免重复一级标题和加载时的零条假象。
- **P2：反馈查询对复制格式过于敏感，提交后缺少下一步。** 规范输入并提供当前会话中的进度查询入口，不扩大查询权限。
- **P2：手机隐藏支持入口。** 保留图标，搜索输入可收缩，主题按钮不挤出视口。

没有改变已确认的主页结构、文案配置、栏目归属、后台入口隔离或数据库业务规则。当前范围没有未解决的 P0/P1/P2。
